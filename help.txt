* `$help`
  * this help
* `$links`
  * useful links
* `$status`
  * print status lines (see also webcam)
* `$search <public/news/ham/marine/rail/air/cb/gmrs/racing/special/weather>`
  * scan preprogrammed frequency ranges
* `$freqrange <min freq> <max freq>`
  * scan through a range of frequencies
* `$freq [<freq in MHz> ...]`
  * add specific frequencies to list of scan candidates
* `$memclear`
  * clear frequencies saved with `$freq`
* `$locked`
  * print locked out systems/groups/channels
* `$lockout <freq>`
  * lock out specific frequencies
* `$unlockall`
  * unlock all locked out systems/groups/channels
* `$tree`
  * print all systems, their groups, and channels
* `$systems`
  * list systems and their IDs
* `$systemadd`
  * add a new system
* `$systemdel <system id>`
  * delete a system
* `$systemname <system id> <name>`
  * set a system's name. limit 16 characters
* `$systemlock <system id> <locked>`
  * set a system's lockout status
* `$groups <system id>`
  * list groups and IDs for the given system
* `$groupadd <system id>`
  * add a new group to a system
* `$groupdel <group id>`
  * delete a group
* `$groupname <group id> <name>`
  * set a group's name. limit 16 characters
* `$grouplock <group id> <locked>`
  * set a group's lockout status
* `$channels <group id>`
  * list channels in a given group
* `$chanadd <group id>`
  * add a new channel to a group
* `$chandel <channel id>`
  * delete a channel
* `$channame <channel id> <name>`
  * set a channel's name. limit 16 characters
* `$chanlock <channel id> <locked>`
  * set a channel's lockout status
* `$chanfreq <channel id> <frequency in MHz>`
  * set a channel's frequency
* `$key <keys>` / `$keyon` / `$keyoff`
  * press a series of buttons on the scanner. case insensitive, whitespace ignored
  * `$keyon`/`$keyoff` toggle treating all messages as keycode inputs (per-user)
  * see list of supported keycodes below
* `$sweep`
  * admin only. delete all messages in the channel :broom::dash:
* `$raw <body>` / `$rawon` / `$rawoff`
  * admin only. allows transmitting raw protocol data
  * `$rawon`/`$rawoff` like keycode commands treats all messages as protocol data
* `$hardclear`
  * admin only. factory reset

Keycodes:
```
M - Menu
F - Function
H - Hold
S - Scan
L - Lockout (L/O)
C - Car
0-9 - Digits
. - Decimal / No
E - Enter / Yes
> - Scroll right
< - Scroll left
^ - Enter
P - Power
```
