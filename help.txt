* `$help`
  * this help
* `$links`
  * useful links
* `$status`
  * prints status lines (see also webcam)
* `$search <public/news/ham/marine/rail/air/cb/gmrs/racing/special/weather>`
  * scans preprogrammed frequency ranges
* `$freqrange <min freq> <max freq>`
  * scan through a range of frequencies
* `$freq [<freq in MHz> ...]`
  * adds specific frequencies to list of scan candidates
* `$memclear`
  * clear frequencies saved with `$freq`
* `$hardclear`
  * factory reset
* `$systems`
  * list systems and their IDs
* `$groups <system id>`
  * list groups and IDs for the given system
* `$channels <group id>`
  * list channels in a given group
* `$key <keys>` / `$keyon` / `$keyoff`
  * presses a series of buttons on the scanner. case insensitive, whitespace ignored
  * `$keyon`/`$keyoff` toggle treating all messages as keycode inputs
  * see list of supported keycodes below
* `$sweep`
  * admin only. deletes all messages in the channel :broom::dash:
* `$raw <body>` / `$rawon` / `$rawoff`
  * admin only. allows transmitting raw protocol data
  * `$rawon`/`$rawoff` like keycode commands treats all messages as protocol data

Keycodes:
```
M - Menu
F - Function
H - Hold
S - Scan
L - Lockout (L/O)
C - Car
0-9 - Digits
. - Decimal / No
E - Enter / Yes
> - Scroll right
< - Scroll left
^ - Enter
P - Power
```
