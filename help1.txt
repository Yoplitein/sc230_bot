## Commands
* `$help`
  * this help
* `$links`
  * useful links
* `$status`
  * print status lines (see also webcam)
* `$search <public/news/ham/marine/rail/air/cb/gmrs/racing/special/weather>`
  * scan preprogrammed frequency ranges
* `$freq <freq in MHz>`
  * tune in to a specific frequency (to nearest 5kHz)
* `$freqrange <min freq> <max freq>`
  * scan through a range of frequencies. overrides custom search group 0
* `$cs [<group ids>]`
  * switch to custom search mode with the given group IDs enabled, defaults to all
* `$csgroups`
  * print custom search groups
* `$csfreq <group id> <min freq> <max freq>`
  * set custom search group min/max frequencies. note that this may be overridden on group 0 by `$freqrange`
* `$csname <group id> <name>`
  * print custom search group name
* `$csall`
  * programs set of search groups covering the hardware's frequency range
* `$lockout <freq>`
  * lock out specific frequencies
* `$unlockall`
  * unlock all locked out systems/groups/channels
* `$tree`
  * print all systems, their groups, and channels
* `$systems`
  * list systems and their IDs
* `$systemadd`
  * add a new system
* `$systemdel <system id>`
  * delete a system
* `$systemname <system id> <name>`
  * set a system's name. limit 16 characters
* `$systemlock <system id> <locked>`
  * set a system's lockout status
* `$groups <system id>`
  * list groups and IDs for the given system
* `$groupadd <system id>`
  * add a new group to a system
* `$groupdel <group id>`
  * delete a group
* `$groupname <group id> <name>`
  * set a group's name. limit 16 characters
* `$grouplock <group id> <locked>`
  * set a group's lockout status
